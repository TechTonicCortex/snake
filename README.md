# Snake

**Classic Snake that you play yourself.** (The self-learning version is [AI Snake](https://github.com/TechTonicCortex/ai-snake).)
Open `index.html` in a browser.

## Controls
Arrow keys or **W A S D**. Click **PLAY** to start and **RETRY** after a crash.

## Features
- Score and a **High Score** shown on screen
- Smooth movement drawn on a canvas

## How it works
A game loop runs many times a second: move the snake one step in its direction, check for food (grow and score), check for walls or its own body (game over), then redraw.

## What I learned
The game loop is the heart of every game. This was the base I reused for AI Snake.

## Next steps
Add speed levels and walls that appear at higher scores.
